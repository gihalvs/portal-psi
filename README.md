# Portal Psi

Plataforma web inovadora de **saúde mental** desenhada para atender de forma igualitária e fluida desde pacientes de menor poder aquisitivo até classes de alto escalão.

O grande diferencial é oferecer **apoio psicológico rápido, desburocratizado e humanizado**, quebrando barreiras e eliminando o estigma em torno da terapia.

## Funcionalidades

- **Header** com logo, navegação e botões Entrar/Cadastrar (menu mobile)
- **Hero** acolhedor com chamada para agendamento
- **Diferenciais**: acesso democrático, agilidade e design humanizado
- **Especialistas**: listagem de profissionais com CRP e especialidade
- **SOS Crises**: botão de emergência para o CVV 188
- **Diário de Humor**: seleção interativa de humor + intensidade
- **Footer** com links, FAQ, contatos e avisos de privacidade (LGPD)

## Tecnologias

- HTML5
- CSS3 (Flexbox/Grid, variáveis CSS, design responsivo)
- JavaScript vanilla (menu mobile, diário de humor, scroll suave)

## Como usar

1. Clone o repositório
2. Abra o arquivo `index.html` no navegador

Ou use um servidor local:

```bash
npx serve .
```

## Deploy rápido

Você pode publicar facilmente no [GitHub Pages](https://pages.github.com/), Netlify ou Vercel.
